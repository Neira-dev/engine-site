Kagura 3D構成図

下から「基盤 → Core → Runtime」が Engine.dll にまとまり、その上に Editor / Player / GameScripts が載ります。流れを選ぶと処理が光って進みます。

処理の流れ

全体

    Engine.dll(青い枠) の中に、基盤層・Core・Runtime モジュールが入っています。Editor のコードは含まれないので、配布用の Player.exe と分けられます。

    右の棚 はプロジェクトフォルダ(Assets/・Scripts/・Library/)、空中の球 は外部AIとローカルLLMです。

    線を流れる光は、上で選べる6つの処理です。ブロックをクリックすると役割が表示されます。

    色の意味

    エンジン本体
    ランタイム / ゲーム
    Editor / ツール
    データ / キャッシュ
    AI 連携
